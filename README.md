# 🎣 Phishing Awareness Training Module

## 📌 Overview

The **Phishing Awareness Training Module** is an interactive, responsive web application developed as part of the **CodeAlpha Cyber Security Internship**. The module educates users about phishing attacks, fake websites, email scams, and social engineering techniques through engaging content, real-world examples, and an interactive quiz.

Unlike a traditional presentation, this project provides a modern learning experience where users can navigate through educational sections and test their knowledge.

---

# 🎯 Objectives

* Educate users about phishing attacks.
* Explain how phishing emails and fake websites work.
* Raise awareness about social engineering tactics.
* Teach best practices to prevent phishing attacks.
* Assess user understanding using an interactive quiz.

# 📖 Learning Modules

The website includes the following educational sections:

## 1. Introduction to Phishing

* What is phishing?
* Why phishing attacks are dangerous
* Common targets

---

## 2. Types of Phishing

* Email Phishing
* Spear Phishing
* Whaling
* Smishing (SMS)
* Vishing (Voice Calls)
* Clone Phishing

---

## 3. Recognizing Phishing Emails

Users learn to identify:

* Suspicious sender addresses
* Fake links
* Urgent language
* Grammar mistakes
* Unexpected attachments
* Requests for sensitive information

---

## 4. Identifying Fake Websites

Topics include:

* Fake URLs
* HTTPS vs HTTP
* Domain spoofing
* Missing security indicators
* Website design inconsistencies

---

## 5. Social Engineering

The module explains attacks such as:

* Pretexting
* Baiting
* Tailgating
* Impersonation
* Scareware

---

## 6. Best Practices

Users learn how to:

* Verify website URLs
* Enable Multi-Factor Authentication (MFA)
* Use strong passwords
* Avoid suspicious links
* Keep software updated
* Report phishing attempts

---

## 7. Interactive Quiz

The quiz helps users evaluate their understanding by:

* Answering multiple-choice questions
* Receiving an instant score
* Reviewing the correct answers
